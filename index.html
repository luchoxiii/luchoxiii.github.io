GestionQuincaillerie: ERP y punto de venta para ferreterías

Sistema full-stack en un monorepo TypeScript (React + Vite, NestJS, PostgreSQL con Prisma y Redis) para ferreterías, corralones y distribuidoras: punto de venta con lector de código de barras, inventario multidepósito, facturación AFIP, presupuestos en pesos y dólares, integración con la API de Mercado Libre y backups en Google Drive. Incluye un módulo de analítica de clientes con métricas RFM, segmentación y un score de churn explicable con acciones de retención sugeridas, además de control de acceso por roles, bitácora de auditoría encadenada con SHA-256, 186 tests automatizados y despliegue con Docker o Podman.
